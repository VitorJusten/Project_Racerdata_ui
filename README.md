# RacerData — Frontend

Interface desktop desenvolvida com **Python + Tkinter**.

---

## Requisitos

- Python **3.11+** instalado
- Dependências do projeto instaladas (`pip install -r requirements.txt`)
- Backend rodando em [http://localhost:8000](http://localhost:8000)

---

## Como rodar

Na pasta do projeto frontend, execute:

```bash
py main.py
```

> Em alguns sistemas pode ser necessário usar `python main.py` ou `python3 main.py`.

---

## Observações

- Certifique-se de que o **backend está em execução** antes de abrir o frontend.
- As configurações de URL da API ficam em `src/api_config.py`.
